# Minecraft Trivia

A browser trivia game for CP1296. Open `index.html` to play the first sample question.

## Where to find things

- `index.html` contains the question, answer choices, and submit button.
- `style.css` controls the layout, colours, and spacing.
- `app.js` checks the selected answer and displays feedback.
